# SentinelOps Visual Identity

## Logo and Branding
SentinelOps uses a minimal, high-contrast visual identity representing security, clarity, and evidence-first analysis. 

## Typography
- **Primary:** Inter (sans-serif) for UI and readability.
- **Monospace:** Fira Code or JetBrains Mono for code blocks, JSON payloads, and log evidence.

## Color Palette
- **Backgrounds:** Deep dark gray `#0F172A` (Tailwind Slate-900)
- **Primary Accent:** Cyber Blue `#38BDF8` (Tailwind Sky-400)
- **Success:** Emerald Green `#34D399` (Tailwind Emerald-400)
- **Warning:** Amber `#FBBF24` (Tailwind Amber-400)
- **Danger:** Rose `#F43F5E` (Tailwind Rose-500)
- **Text:** Slate `#F8FAFC` for high-contrast primary text, `#94A3B8` for secondary information.

## Layout Principles
- **Evidence First:** The UI prioritizes raw data visibility. JSON blocks are collapsible but always accessible.
- **Tenant Isolation:** Visual indicators strictly declare the active tenant environment.
- **Privacy Awareness:** Tokenized fields (e.g. `USER_A7F3_001`, `PRIVATE_IP_...`) are highlighted with distinct inline badges to show they have been safely transformed by the Local Privacy Gateway.
